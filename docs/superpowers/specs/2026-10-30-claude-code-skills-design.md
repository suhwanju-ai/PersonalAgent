# Claude Code 스킬 호환 확장 — 설계(Spec)

날짜: 2026-10-30 · 대상: Common Agent (표준 라이브러리만, 한국어 UI)

## 1. 배경

`lab/skills.py`는 이미 `skills/<이름>/SKILL.md`를 읽어 `use_skill` 도구 하나로 노출한다(오케스트레이터만 사용).
다만 Claude Code 스킬을 **그대로 가져다 쓰기에는** 다음이 막혀 있다.

| 막힌 곳 | 현재 동작 | 결과 |
|---|---|---|
| 머리말 파서 | 한 줄 `key: value`만 읽음 | `description: >` / `|` 블록을 쓰는 실제 스킬은 설명이 `>`나 빈 값이 됨 |
| 설명 길이 | 300자에서 자름 | 트리거 문구가 잘림 |
| `allowed-tools`, `when_to_use`, `disable-model-invocation` | 무시 | 모델에게 보이면 안 되는 스킬도 노출, 필요한 도구 정보 소실 |
| `references/` 등 동봉 파일 | 읽을 방법 없음 | 본문이 "references/x.md를 읽어라"고 해도 불가능 |
| 가져오기 | 화면에서 직접 쓰기만 가능 | 이미 있는 `~/.claude/skills`를 손으로 옮겨야 함 |

## 2. 목표 / 비목표

**목표**
1. Claude Code `SKILL.md` 머리말의 실용적 부분집합을 정확히 읽는다.
2. 스킬 폴더 안 **텍스트 참고 파일**을 모델이 필요할 때 읽을 수 있게 한다(점진적 공개).
3. `~/.claude/skills`의 스킬을 화면에서 골라 가져온다. 코드는 가져오지 않고, 못 가져온 것은 이유를 보여 준다.

**비목표** (하지 않는다)
- 스킬 안 스크립트·명령 실행(`scripts/`, `` !`cmd` ``, Bash). `run_python`은 계속 꺼져 있고, 스킬은 코드를 실행하지 않는다.
- `$ARGUMENTS` 치환, `/스킬이름` 슬래시 호출, 훅, `context: fork`, 플러그인·마켓플레이스.
- 연구원(researcher) 프로세스에 스킬 노출. 오케스트레이터만 쓴다(현행 유지).
- zip·폴더 업로드, 임의 경로 가져오기.

## 3. 요구사항

**R1 머리말.** `---` 사이를 YAML 부분집합으로 읽는다: 한 줄 값, 짝 맞는 따옴표, 블록 스칼라 `>` `>-`(줄을 공백으로 접음) `|` `|-`(줄바꿈 유지), 들여쓴 이어지는 줄. 키는 소문자로 비교한다.
`description`은 공백을 접어 **500자**까지(현재 300). `when_to_use`가 있으면 description 뒤에 이어 붙인 뒤 500자로 자른다. 저장(`save`)의 설명 한도도 500자로 맞춘다.

**R2 도구 선언.** `tools` 또는 `allowed-tools`(쉼표·공백 구분, `[a, b]` 형태 허용)를 읽는다. `SKILL_TOOLS`에 있는 이름만 유효하다. 나머지(`Bash`, `Read` 등)는 무시하되 `unsupported_tools`에 기록해 화면에 보여 준다.

**R3 모델 호출 금지.** `disable-model-invocation: true`인 스킬은 `use_skill`의 목록·enum·도구 선언에서 뺀다. 화면에는 "모델 호출 금지"로 표시한다.

**R4 참고 파일.** 스킬 폴더 안에서 `SKILL.md`를 뺀 `.md .txt .json .csv .yaml .yml` 파일(깊이 3, 스킬당 100개까지)이 참고 파일이다.
- `use_skill` 결과에 `"참고 파일": [상대경로…]`를 싣는다(있을 때만).
- 새 도구 `read_skill_file(skill, path)`: 폴더 안의 참고 파일 하나를 돌려준다. 최대 20000자, 넘으면 잘라서 `"잘림": true`. 폴더 밖·참고 파일 아닌 것·읽을 수 없는 것은 `{"오류": …}`(예외 아님).
- 참고 파일이 있는 스킬이 하나도 없으면 이 도구는 모델에게 주지 않는다.

**R5 스크립트는 읽지도 복사하지도 않는다.** `scripts/` 폴더와 허용 확장자 밖 파일은 참고 파일에 들지 않고 가져올 때 복사하지 않는다. 가져오기 결과에 "건너뜀" 목록으로 알린다.

**R6 가져오기.**
- 원본 폴더: `~/.claude/skills`. 환경 변수 `SKILLS_IMPORT_DIR`로 바꿀 수 있다(호출 때마다 읽는다).
- 클라이언트는 **폴더 이름만** 보낸다. 서버는 원본 폴더를 직접 나열해 그 안에 있는 이름일 때만 처리한다(경로를 받지 않는다).
- 이름 규칙(`[a-z0-9][a-z0-9_-]{0,39}`, 대문자는 소문자로)에 안 맞는 스킬은 목록에 "가져올 수 없음 + 이유"로 보여 주고 거부한다.
- 같은 이름이 이미 있으면 `overwrite=true` 없이는 거부한다(화면은 확인을 받는다).
- 한도: 스킬 총 `MAX_SKILLS`(30) 유지, 스킬당 파일 40개, 파일당 60KB, 합계 300KB, `SKILL.md`는 `MAX_BYTES`. 넘으면 그 파일을 건너뛰고 알린다(SKILL.md가 넘으면 전체 거부).
- 심볼릭 링크·정션은 따라가지 않는다(`realpath`가 원본 폴더 밖이면 건너뜀).
- 복사 도중 실패해도 기존 스킬이 반쯤 바뀐 상태로 남지 않는다(임시 폴더에 만든 뒤 교체).

**R7 화면.** 스킬 카드에 "Claude Code 스킬 가져오기" 버튼 → 목록(이름·설명·참고 파일 수·건너뜀·가져올 수 없는 이유) → 선택해 가져오기. 스킬 행에는 "참고 파일 N", "모델 호출 금지", "지원 안 하는 도구: …" 표시를 단다.

**R7b 붙여 넣기도 같은 파서.** 스킬 팝업의 "SKILL.md 붙여 넣기"(`static/app.js` `importSkillMd`)는 지금 JS로 머리말을 따로 읽어 한 줄 값만 안다. 이 JS 파서를 지우고 서버 `POST /api/skills/parse {text}`를 부른다. 서버가 R1~R3과 같은 파서로 `{name, description, tools, body, notes}`를 돌려준다. 파서가 한 곳이 되어야 두 경로의 결과가 어긋나지 않는다. 팝업의 설명 입력 `maxlength`도 500으로 맞춘다.

**R8 화면 편집.** 화면에서 저장하면 `SKILL.md`만 다시 쓰고 동봉 폴더는 그대로 둔다. 지원하지 않는 머리말 키(`disable-model-invocation` 등)는 저장 때 사라진다(알려진 동작, 화면에 한 줄 안내).

**R9 숨김 폴더.** 이름이 `.`로 시작하는 폴더(가져오기 임시 폴더)는 스킬로 읽지 않는다.

## 4. 보안 경계

- 스킬은 여전히 글과 `SKILL_TOOLS`·`read_skill_file`뿐이다. 새 코드 실행 경로 없음.
- `read_skill_file`은 `os.path.realpath`로 푼 경로가 스킬 폴더의 realpath 안일 때만 읽는다. 절대경로, 드라이브 문자, `..`, 역슬래시, 링크 탈출을 모두 거부한다.
- 가져오기는 고정된 원본 폴더 하나만 읽는다. 사용자 입력은 "그 폴더에 있는 이름"으로만 쓰인다.
- 스킬 본문과 참고 파일은 신뢰할 수 없는 텍스트다. 모델에게 지침으로 전달되지만 키·비밀은 어디에도 싣지 않는다(기존 규칙 유지).
- 오류 문구에 절대경로를 싣지 않는다.

## 5. 수용 기준

1. `description: >` 블록 설명을 가진 Claude Code 스킬이 한 줄 설명으로 등록된다.
2. `references/guide.md`가 있는 스킬을 가져온 뒤, 오케스트레이터가 `use_skill` → `read_skill_file`로 그 내용을 읽는다.
3. `scripts/run.py`는 복사되지 않고 "건너뜀"에 나온다.
4. `read_skill_file`에 `../`, 절대경로, `scripts/run.py`를 주면 오류 사전이 돌아오고 예외가 없다.
5. 같은 이름 가져오기는 `overwrite` 없이 거부된다.
6. `disable-model-invocation: true` 스킬은 `use_skill` enum에 없다.
7. 기존 `html` 스킬과 화면 저장/삭제가 그대로 동작한다.
8. `description: >` 블록이 든 SKILL.md를 팝업에 붙여 넣어도 설명 칸이 한 줄로 채워진다.

## 6. 정해 둔 기본값 (이견이 있으면 바꾼다)

- 원본 폴더는 `~/.claude/skills` 하나(프로젝트별 `.claude/skills`는 제외).
- 참고 파일은 텍스트 확장자 6종만. 이미지·PDF는 비목표.
- 테스트는 표준 라이브러리 `unittest`로 `tests/test_skills.py`를 새로 둔다(저장소에는 지금 테스트 스위트가 없다).
